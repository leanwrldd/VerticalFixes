Fixes a bunch of logistics bugs and annoyances: belts, lifts, pipes, mergers and splitters.

## What it fixes

Fixes lifts and vertical attachments. The Better Straight pipe build mode that used to be here has moved to the Follow Terrain (Terrain Belts) mod.

## Reported issues it addresses

- [Placing Vertical Splitters/Mergers on lifts disconnect the lift from the floor holes](https://questions.satisfactorygame.com/post/6828fb5a6b7c57319637b4a0)
- [Vertical conveyor connections breaking when using splitters and mergers inside a blueprint editor](https://questions.satisfactorygame.com/post/67f2a5546b7c573196364543)
- [locking vertical splitters/mergers doesn't work](https://questions.satisfactorygame.com/post/67ed45ca6b7c573196362c45)
- [Inconsistent conveyor lift height when built off of a splitter/merger](https://questions.satisfactorygame.com/post/67ec650a6b7c573196362747)
- [Lifts with vertical Splitters/Mergers/etc. in a Blueprint don't get dismantled](https://questions.satisfactorygame.com/post/67f1956e6b7c573196363f78)
- [Conveyor lifts snapped from an empty Conveyor pole to an output do not function.](https://questions.satisfactorygame.com/post/69b9b136f991d027c5704204)
- [Unable to snap lift end into top/bottom of vertical splitter/merger](https://questions.satisfactorygame.com/post/67ec20296b7c5731963624e3)
- [Merger and splitter not going back into normal in the build menu after aiming at a vertical conveyor](https://questions.satisfactorygame.com/post/6802bdc96b7c573196367ce9)
- [Feature Request: Independently-buildable Vertical Merger/Splitter, and/or snap to floor holes](https://questions.satisfactorygame.com/post/67ec19966b7c573196362493)
- [Changing the input location on Vertical Splitters/Mergers](https://questions.satisfactorygame.com/post/67ec1e606b7c5731963624c6)

## Known limitations

**Dedicated servers and multiplayer are untested.** If you run it on a server or in co-op and something looks wrong, especially flow direction appearing backwards for non-host players, please report it.
